# k8s-demo-app

Projeto de estudos de CI/CD e Kubernetes.

## Objetivo

Aplicação PHP simples que exibe a versão do produto.  
A versão será atualizada através da esteira de CI/CD.

## Estrutura

- `src/` → código PHP
- `k8s/` → manifests Kubernetes
- `Dockerfile` → imagem da aplicação
- `VERSION` → versão atual

## Grupo de estudos

Repositório colaborativo para aprendizado de:
- Docker
- Kubernetes
- CI/CD
- GitOps
